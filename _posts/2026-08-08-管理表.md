一.修改表:
1.增加字段
alter 表名
add 名 double(总位数,小数位)
2.修改字段
alter 表名
modify  名 varchar(数字)
3.重复名字段
alter 表名
change 旧名 新名 varchar(数字)
可以改名同时改长度
4.删除字段
alter 表名
drop column 名

二.重命名表
rename table 旧名
to 新名

三.删除表
drop table if exists 名

四.清空表
truncate table  名

五.添加字段
insert into 名(a,b,c)
values
(1,2,3)
(1,2,3)
...添加多条数据

六.更新数据
update 表名
set 列名1=需更新内容,列名2=需更新内容
where id id=5;(定位)
