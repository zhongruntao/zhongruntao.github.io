## 关于博客

本博客基于 [Jekyll](https://jekyllrb.com/) 构建，纯静态站点，轻量且高效。

**技术栈：**

| 类别 | 说明 |
| --- | --- |
| 站点生成 | Jekyll 3.8.5 |
| 代码高亮 | Rouge 3.11.0 |
| 前端 | 原生 HTML / CSS / JS |
| 部署 | GitHub Pages 或腾讯云 COS + CDN |

**主要特性：**

- 明暗主题切换，点击页头头像即可切换
- 客户端站内搜索，无需后端
- 分类归档，按年份分组展示
- 代码高亮（深浅双套主题）
- 图片全屏预览
- MathJax 数学公式渲染
- PWA 离线缓存支持
